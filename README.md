# 💬 Kotlin DeepSeek Chat Server

Минималистичный веб-сервер на **Kotlin** с использованием фреймворка **Ktor**, который предоставляет интерфейс для общения с нейросетью **DeepSeek**. Приложение полностью сохраняет контекст и историю текущей переписки.

Проект создан методом «вайб-кодинга» без использования тяжелых сред разработки (IDE) и оптимизирован для быстрого деплоя на облачные платформы (Render, Railway).

## ✨ Особенности
* **Сохранение контекста:** Сервер запоминает историю реплик и передает её в API DeepSeek при каждом новом запросе.
* **Веб-интерфейс:** Простой HTML/CSS чат-бокс, доступный прямо в браузере по ссылке.
* **Легковесность:** Написан на Ktor (Netty) и Kotlinx.Serialization без избыточных библиотек.
* **Безопасность:** API-ключ не зашит в код, а безопасно считывается из переменных окружения (`DEEPSEEK_API_KEY`).

## 🛠 Стек технологий
* **Language:** Kotlin 2.0
* **Framework:** Ktor Server (Netty) & Ktor Client (CIO)
* **UI:** Ktor HTML Builder
* **Data Format:** JSON (Kotlinx Serialization)

## 🚀 Как запустить локально
1. Клонируйте репозиторий.
2. Установите вашу переменную окружения:
   ```bash
   export DEEPSEEK_API_KEY="ваш_ключ_api"
   ```
3. Запустите проект через Gradle:
   ```bash
   ./gradlew run
   ```
4. Откройте в браузере: `http://localhost:8080`

## ☁️ Деплой
Приложение полностью готово к автоматической сборке на **Render.com** или **Railway.app** при связке с вашим GitHub-аккаунтом. Не забудьте указать `DEEPSEEK_API_KEY` в настройках Environment переменных вашего хостинга.
